Les marques et compagnies de cars visibles dans le jeu sont **fictives** tant qu'aucun accord écrit n'est signé avec un partenaire. Les publicités sont celles que réservent et paient les annonceurs, validées par l'équipe ; aucune n'est livrée avec le jeu (voir le document de conception, « Marques réelles »). Les lieux publics de Lomé (marchés, monuments, aéroport, CHU, université) sont nommés d'après leurs noms réels.
